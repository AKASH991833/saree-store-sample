Manage products & stock

How this works: everything you change here is saved in this browser only, so you can preview it on the shop pages of this device. Customers see your changes only after you publish: tap Publish updates below to download an update file - nothing is sent by this page - then send that file yourself in your Instinct WhatsApp chat (the same chat where this website was made). New product photos go in that chat too, with their product codes. The site then updates for everyone. There is no login on this page yet — changes stay on each device until published.

✦
